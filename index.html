For Bambu Studio: import the STL, keep the flat back on the build plate, slice, and inspect layers before printing. STL is a single-colour geometry format. A computer browser is the most reliable way to save and transfer STL files.

Live preview

Preview requires Canvas support.
Version 0.2: Generates a single connected height-field mesh with a real hole in the hanging loop. Lettering and borders are fused into the mesh. Edges are grid-based (0.6 mm resolution), so some curves are stepped. Print quality is not yet physically validated.
Standalone app · No external libraries or server required · STL coordinates in millimetres
